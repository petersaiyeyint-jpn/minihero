# MoneyFlow v3

Includes Dashboard, money-flow trend, Focus BI, time-aware Home greeting, latest-transaction focus, dark mode, animated UI, offline PWA, and Google Sheets Apps Script sync.

## Google Sheets
1. Open Google Sheet → Extensions → Apps Script.
2. Paste `google-apps-script/Code.gs`.
3. Leave `SPREADSHEET_ID` blank for a bound script, or enter the Sheet ID for a standalone script.
4. Deploy as Web App, execute as you, choose suitable access.
5. Copy `/exec` URL into Settings → Google Sheets sync.
6. Test, Push, or Pull.
